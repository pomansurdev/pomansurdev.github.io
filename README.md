# twig2tpl — онлайн-конвертер Twig → TPL

Страница: https://pomansurdev.github.io/twig2tpl/

Конвертер Twig-шаблонов OpenCart 3 в PHP-шаблоны (.tpl) для порта на OpenCart 2.3.

- `index.html` — интерфейс конвертера
- `assets/twig2tpl.js` — ядро (UMD-модуль, без зависимостей)
- `assets/batch.js` — пакетная конвертация папки шаблонов с выгрузкой в ZIP

## Авторы

- **pomansurdev** — ядро конвертера, порт и интерфейс
- **AutoClaw** (AI-агент) — публикация, сборка и поддержка страницы
